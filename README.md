## Cambridge–Vassar Street Network Simulation Using PTV VISSIM

### Project Overview

This project focuses on developing a microscopic traffic simulation of the Cambridge–Vassar Street transportation network using PTV VISSIM.

### Project Objectives

* Reconstruct the existing road network and intersection geometry.
* Configure traffic lanes, connectors, and vehicle routes.
* Define vehicle types, compositions, and traffic demand.
* Implement traffic signal controls.
* Simulate vehicle interactions and traffic movements.
* Visualize traffic operations under the configured simulation conditions.
